Below is implementation-oriented pseudocode for **Adjoint Matching fine-tuning of a flow-matching model**.

Adjoint Matching interprets reward fine-tuning as the stochastic optimal-control problem

[
\min_u
\mathbb E\left[
\frac12\int_0^1 |u(X_t,t)|^2dt
+g(X_1)
\right],
]

with

[
dX_t=
\left[b_{\mathrm{ref}}(X_t,t)+\sigma(t)u_\theta(X_t,t)\right]dt
+\sigma(t)dB_t,
]

where typically

[
g(x)=-\lambda r(x).
]

The control-energy term is the path-space KL regularizer to the frozen reference process. Adjoint Matching therefore already includes KL regularization; no separate empirical KL loss is added. 

## Adjoint Matching objective

For a trajectory generated by the current policy, define the **lean adjoint**

[
\frac{d\widetilde a_t}{dt}
==========================

-\left[
\nabla_x b_{\mathrm{ref}}(X_t,t)^\top\widetilde a_t
+
\nabla_x f(X_t,t)
\right],
]

with terminal condition

[
\widetilde a_1=\nabla_x g(X_1).
]

For terminal-reward fine-tuning, (f=0), so

[
\frac{d\widetilde a_t}{dt}
==========================

-\nabla_x b_{\mathrm{ref}}(X_t,t)^\top\widetilde a_t.
]

The control is trained with

[
\mathcal L_{\mathrm{AM}}(\theta)
================================

\frac12,
\mathbb E\left[
\int_0^1
\left|
u_\theta(X_t,t)
+
\sigma(t)^\top \widetilde a_t
\right|^2dt
\right].
]

Crucially, the sampled trajectory and lean-adjoint targets are stop-gradient quantities in this regression loss. 

---

## Pseudocode

```text
Algorithm: Adjoint Matching for Reward Fine-Tuning

Require:
    frozen pretrained/reference model M_ref
    trainable model M_theta, initialized from M_ref

    differentiable reward r(x_final, condition)
    reward scale lambda_reward

    base distribution p0
    memoryless SDE schedule sigma(t)
    reference drift b_ref(x, t, condition)
    current controlled drift b_theta(x, t, condition)
    reference-relative control u_theta(x, t, condition)

    number of optimization iterations N
    batch size B
    number of SDE steps K
    optimizer learning rate eta
    optional running state cost f(x, t)
        # Set f = 0 for ordinary terminal-reward fine-tuning.

Initialize:
    theta <- parameters(M_ref)
    freeze(M_ref)

    Choose an interior time grid:
        0 < t_0 < t_1 < ... < t_K < 1

    # Avoid evaluating singular memoryless coefficients exactly
    # at t = 0 or t = 1.

for iteration = 1, ..., N:

    # ============================================================
    # 1. Generate on-policy trajectories with the current model
    # ============================================================

    sample conditions c_1, ..., c_B
    X_0 <- sample from p0

    trajectory_states <- [stop_gradient(X_0)]
    trajectory_noises <- empty

    for k = 0, ..., K - 1:

        t  <- t_k
        dt <- t_{k+1} - t_k

        with no_gradient:

            # The current model defines the controlled process:
            #
            # b_theta = b_ref + sigma * u_theta
            #
            drift <- b_theta(X_k, t, c)

            epsilon_k <- Normal(0, I)

            X_{k+1} <- X_k
                       + drift * dt
                       + sigma(t) * sqrt(dt) * epsilon_k

        trajectory_states.append(stop_gradient(X_{k+1}))
        trajectory_noises.append(epsilon_k)

    # ============================================================
    # 2. Compute the terminal lean-adjoint condition
    # ============================================================

    X_K_grad <- detach(X_K)
    enable_gradient(X_K_grad)

    # Terminal cost g(x) = -lambda_reward * r(x).
    terminal_cost <- -lambda_reward * r(
        postprocess(X_K_grad),
        c
    )

    a_K <- gradient(
        sum(terminal_cost),
        with_respect_to = X_K_grad
    )

    a_K <- stop_gradient(a_K)

    adjoint_targets[K] <- a_K

    # ============================================================
    # 3. Solve the lean adjoint backward along the trajectory
    # ============================================================

    for k = K - 1, ..., 0:

        t  <- t_k
        dt <- t_{k+1} - t_k

        X_k_grad <- detach(trajectory_states[k])
        enable_gradient(X_k_grad)

        a_next <- stop_gradient(adjoint_targets[k + 1])

        # Frozen reference drift. We need derivatives with respect
        # to the state, but never with respect to reference weights.
        b <- b_ref(X_k_grad, t, c)

        # Compute J_b(x,t)^T a without constructing the full Jacobian.
        drift_vjp <- gradient(
            sum(inner_product(b, a_next)),
            with_respect_to = X_k_grad
        )

        if running state cost f is not zero:
            state_cost <- f(X_k_grad, t, c)
            state_cost_grad <- gradient(
                sum(state_cost),
                with_respect_to = X_k_grad
            )
        else:
            state_cost_grad <- zeros_like(X_k_grad)

        # Lean adjoint ODE:
        #
        # da/dt = -J_b^T a - grad_x f.
        #
        # Integrating backward from t_{k+1} to t_k gives:
        #
        # a_k = a_{k+1}
        #       + dt * (J_b^T a_{k+1} + grad_x f).
        #
        a_k <- a_next + dt * (
            drift_vjp + state_cost_grad
        )

        adjoint_targets[k] <- stop_gradient(a_k)

    # ============================================================
    # 4. Regress the current control onto the adjoint target
    # ============================================================

    loss <- 0

    # All trajectory states and adjoint targets are detached.
    # Gradients flow only through u_theta.
    for k = 0, ..., K - 1:

        X_k <- stop_gradient(trajectory_states[k])
        a_k <- stop_gradient(adjoint_targets[k])
        t   <- t_k
        dt  <- t_{k+1} - t_k

        u_pred <- u_theta(X_k, t, c)

        # Optimal regression target:
        #
        # u_target = -sigma(t)^T a_k
        #
        u_target <- -transpose(sigma(t)) @ a_k

        step_loss <- 0.5 * squared_norm(
            u_pred - u_target
        )

        loss <- loss + dt * mean_over_batch(step_loss)

    optimizer.zero_grad()
    backpropagate(loss)
    clip_gradient_norm(theta)
    optimizer.step()

return M_theta
```

## Flow-matching specialization

For a reference interpolation

[
\bar X_t=\beta_t X_0+\alpha_t X_1,
]

define

[
\eta_t
======

\beta_t\left(
\frac{\dot\alpha_t}{\alpha_t}\beta_t-\dot\beta_t
\right).
]

Adjoint Matching must use the **memoryless schedule**

[
\sigma(t)^2=2\eta_t
]

during fine-tuning. This schedule removes the initial-noise bias and makes the optimal terminal distribution

[
p^\star(x)
\propto
p_{\mathrm{ref}}(x)e^{\lambda r(x)}.
]

After fine-tuning, the model may again be sampled with an arbitrary supported schedule, including its deterministic flow ODE. 

For flow-matching velocity fields, the paper gives

[
b_\theta(x,t)
=============

## 2v_\theta(x,t)

\frac{\dot\alpha_t}{\alpha_t}x,
]

and

[
u_\theta(x,t)
=============

\sqrt{
\frac{2}{
\beta_t
\left(
\frac{\dot\alpha_t}{\alpha_t}\beta_t-\dot\beta_t
\right)
}
}
\left[
v_\theta(x,t)-v_{\mathrm{ref}}(x,t)
\right].
]

Thus the flow-specific methods in the pseudocode are

```text
function b_ref(x, t, c):
    v_ref <- M_ref(x, t, c)

    return 2 * v_ref
           - alpha_dot(t) / alpha(t) * x


function b_theta(x, t, c):
    v_theta <- M_theta(x, t, c)

    return 2 * v_theta
           - alpha_dot(t) / alpha(t) * x


function u_theta(x, t, c):
    v_theta <- M_theta(x, t, c)
    v_ref   <- stop_gradient(M_ref(x, t, c))

    eta_t <- beta(t) * (
        alpha_dot(t) / alpha(t) * beta(t)
        - beta_dot(t)
    )

    control_scale <- sqrt(2 / eta_t)

    return control_scale * (v_theta - v_ref)


function sigma(t):
    eta_t <- beta(t) * (
        alpha_dot(t) / alpha(t) * beta(t)
        - beta_dot(t)
    )

    return sqrt(2 * eta_t)
```

Equivalently, because the memoryless drift satisfies

[
b_\theta=b_{\mathrm{ref}}+\sigma u_\theta,
]

one can define the control in a modality-agnostic implementation as

[
u_\theta(x,t)
=============

\frac{
b_\theta(x,t)-b_{\mathrm{ref}}(x,t)
}{
\sigma(t)
}.
]

The exact flow-specific conversion above follows the paper’s derivation. 

## Important implementation details

1. **The reward must be differentiable.** The terminal adjoint requires

[
\widetilde a_1
==============

-\lambda\nabla_x r(X_1).
]

A black-box reward cannot be used directly without first learning a differentiable surrogate.

2. **Use the frozen reference drift in the lean-adjoint equation.** Do not use the current controlled drift. The lean formulation deliberately removes the current-control Jacobian and control-energy-gradient terms.

3. **Do not place the reference-drift evaluation inside `no_grad`.** Reference parameters are frozen, but gradients with respect to (X_t) are required to compute the vector–Jacobian product

[
\nabla_xb_{\mathrm{ref}}(X_t,t)^\top\widetilde a_t.
]

4. **Detach the rollout and adjoint targets during regression.** Adjoint Matching is not full backpropagation through the sampler. The model update comes from matching (u_\theta(X_t,t)) to (-\sigma^\top\widetilde a_t).

5. **Avoid explicitly constructing Jacobians.** Compute (J_b^\top a) with a vector–Jacobian product, such as:

```python
drift_vjp = torch.autograd.grad(
    outputs=drift,
    inputs=x,
    grad_outputs=adjoint,
    create_graph=False,
)[0]
```

6. **The KL coefficient is controlled by reward scaling.** For the objective

[
\max_p
\lambda,\mathbb E_p[r]
----------------------

D_{\mathrm{KL}}(p\Vert p_{\mathrm{ref}}),
]

use (g=-\lambda r). Equivalently, for

[
\max_p
\mathbb E_p[r]
--------------

\beta D_{\mathrm{KL}}(p\Vert p_{\mathrm{ref}}),
]

set

[
\lambda=\frac1\beta.
]
